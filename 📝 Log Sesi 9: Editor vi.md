🎯 Materi yang Dipelajari
Editor vi: Editor teks berbasis terminal yang wajib dikuasai.

Dua mode utama: Command Mode dan Insert Mode.

🧠 Konsep Kunci
Command Mode: Mode default. Tombol berfungsi sebagai perintah (bukan untuk mengetik).

Insert Mode: Mode untuk mengetik teks. Tekan i untuk masuk, Esc untuk keluar.

:wq: Menyimpan dan keluar.

:q!: Keluar paksa tanpa menyimpan.

dd: Menghapus satu baris.

💻 Perintah Dasar vi
Perintah	Fungsi
vi nama_file.txt	Membuka/membuat file.
i	Masuk Insert Mode.
Esc	Kembali ke Command Mode.
:wq	Simpan dan keluar.
:q!	Keluar tanpa simpan.
dd	Hapus satu baris.
yy	Kopi satu baris.
p	Tempel baris yang dikopi.
